# Skills Directory

This directory contains custom Claude Code skills for the Navi MVP project.

## Structure

Place skill definition files (`.md`) in this directory. Each skill file should follow the Claude Code skill format:

```markdown
---
name: skill-name
description: Brief description of what the skill does
---

# Skill Name

Instructions for the skill...
```

## Usage

Skills can be invoked using the `/skill-name` command in Claude Code conversations.
